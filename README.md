# DriverFi

Dataset release repository for **DriverFi: Joint Driver Identification and Behavior Recognition via Disentangled WiFi Sensing**.

DriverFi studies joint driver behavior recognition and driver identification using in-cabin WiFi channel state information (CSI).

## Dataset overview

- Three vehicles and four participants.
- Six predefined actions: looking down, turning the head left, turning the head right, hands off the steering wheel, reaching backward for an object, and yawning.
- Recordings collected in stationary vehicles with only the driver present.
- Commercial WiFi CSI acquisition, with the transmitter on the center console and receiver on the front-left dashboard.

## Release status

The dataset will be made publicly available through this repository. **Raw recordings have not yet been uploaded.** Data files, the verified sample inventory, label mappings, preprocessing instructions and evaluation partitions will be added as the release is prepared.

This repository is the public landing page for the planned release. Dataset download instructions and licensing information will be provided with the data release.
